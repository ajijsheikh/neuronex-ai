# UI/UX Specification

## 1. Design Language
*   **Theme:** Dark mode by default (sleek, hacker-friendly, futuristic).
*   **Palette:**
    *   Background: `#09090b` (Zinc-950)
    *   Surface: `#18181b` (Zinc-900)
    *   Primary: `#3b82f6` (Blue-500) for nodes/accents.
    *   Secondary: `#10b981` (Emerald-500) for success states.
    *   Text: `#f8fafc` (Slate-50) for primary text, `#94a3b8` (Slate-400) for muted text.
*   **Typography:** Inter (Sans-serif) for UI, JetBrains Mono for code blocks / citations.
*   **Components:** Built entirely with Shadcn UI and Tailwind CSS.

## 2. Core Layouts

### 2.1 The Dashboard (`/dashboard`)
A split-pane layout to maximize usable space for the graph.
*   **Left Sidebar (Collapsible - 250px):**
    *   User Profile / Logout.
    *   "Upload Document" Dropzone (Drag and drop anywhere to upload).
    *   List of Recent Documents.
*   **Main Canvas (Flex-1):**
    *   The interactive Knowledge Graph (React Flow canvas). Takes up the majority of the screen.
    *   Floating toolbar (Bottom Center): Zoom In/Out, Fit View, 2D/3D Toggle.
*   **Right Sidebar (Collapsible - 350px):**
    *   **State 1 (Default):** AI Chat Assistant. Input field fixed at the bottom.
    *   **State 2 (Node Clicked):** Entity Details Panel. Shows Node Name, Type, connected Documents, and a summary generated by AI.

## 3. User Flows

### Flow 1: Ingestion
1.  User drags a PDF over the browser window. An overlay appears: "Drop to feed your brain."
2.  File drops. A Shadcn Toast appears: "Uploading..." -> "Extracting Entities..." -> "Graph Updated."
3.  The React Flow canvas animates slightly as new nodes pop into existence and draw lines to existing nodes.

### Flow 2: Exploration
1.  User pans around the graph.
2.  User clicks a node labeled "Quantum Computing".
3.  The graph focuses/zooms to that node. Adjacent nodes are highlighted; unrelated nodes fade to 20% opacity.
4.  The Right Sidebar opens to show the "Quantum Computing" summary and lists the 3 PDFs that mention it.

### Flow 3: Conversation
1.  User types in the chat pane: "Summarize my notes on Quantum Computing."
2.  Message bubble appears with a loading skeleton.
3.  Text streams in. Certain words are highlighted as clickable pills (Citations).
4.  Clicking a citation pill opens a modal overlay showing the exact PDF chunk.

## 4. Component Breakdown (Shadcn UI)
*   `Button`: For actions, toggles, and form submissions.
*   `Card`: For document list items.
*   `Sheet`: For the Right Sidebar (slides in from the right).
*   `ScrollArea`: Custom scrollbars for the chat history and document lists.
*   `Toast` & `Toaster`: For all async processing notifications.
*   `Tooltip`: For explaining graph node types on hover.
